[PANTHEON NOTE STANDARD - PLX v1.0]

PLX (Pillara Extensible) is the official structured note format for the Pantheon Note Builder.
It uses bracketed tags to define blocks of content.

[H1] Header 1 - Main Title
[H2] Header 2 - Subtitle
[MATH] LaTeX equation (e.g. E=mc^2)
[LIST] Bullet point list
[ORDERED] Numbered list
[TABLE] Markdown table syntax
[VIDEO] URL to a video (YouTube/Vimeo)
[DIAGRAM] Mermaid or text-based diagram

FILE EXTENSION: .plx
CONTENT TYPE: text/plain

HOW TO USE WITH AI:
1. Copy this standard.
2. Ask AI: "Generate a summary of the provided text using the Pantheon PLX standard."
3. Save the output as a .plx file.
4. Upload to Pantheon Magic Note Creator.
