# Pantheon FLUX

The extracurricular wing of the Pantheon ecosystem.

## Overview

FLUX is designed to help students track their passions beyond the classroom. It shares the same authentication system and activation logic as the main Pantheon platform.

### Key Features

- **Skill Tracks:** Structured paths for learning non-academic skills.
- **Clubs:** Management and discovery for student-led organizations.
- **Global Competitions:** Integration with major student competitions.
- **Unified Identity:** Your Pantheon activation carries over here.

## Tech Stack

- React + Vite
- TypeScript
- Tailwind CSS
- Firebase (Firestore & Auth)
- Framer Motion

## Deployment

Deployed on Wasmer at `flux.pantheon.com.ng`.

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
